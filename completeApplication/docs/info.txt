				> Einarbeitung in React Konzepte: Komponenten, Routing
					- React ist eine JavaScript-Bibliothek für die Entwicklung von Benutzeroberflächen (User Interfaces, UIs).
					- React ermöglicht die Erstellung von wiederverwendbaren UI-Komponenten, die modular und flexibel sind.
					- Sie basiert auf dem Konzept des virtuellen DOM, was effizientere Aktualisierungen und bessere Performance erlaubt.
					- Besonders geeignet für Single-Page-Applications (SPAs) und komplexe Web-UIs.
					- React ist das Framework, JSX ist eine bequeme Schreibweise, um mit React zu arbeiten:
					- Einführung in JSX und Komponenten
						JSX: Eine Erweiterung von JavaScript, mit der man HTML-ähnlichen Code direkt im JavaScript schreiben kann.
						Komponenten: Wiederverwendbare UI-Bausteine, die die Struktur der Anwendung modularisieren.
						Funktionale Komponenten: JavaScript-Funktionen, die JSX zurückgeben.
						Klassenkomponenten: Komplexere Komponenten mit eigenen Zuständen (State) und Lebenszyklusmethoden.
					- State und Props:
						State: Interne Daten einer Komponente, die sich im Laufe der Zeit ändern können.
						Props: Daten, die von einer Elternkomponente an eine Kindkomponente übergeben werden.
						🎯 Analogie
						State ist wie das Gedächtnis einer Komponente.
						Props sind wie Informationen von außen, die die Komponente erhält.
					-Verwaltung des Komponentenstates mit useState
						useState-Hook: Ermöglicht die Verwendung von State in funktionalen Komponenten.
							Gibt ein Array mit zwei Werten zurück:
							- Den aktuellen State-Wert.
							- Eine Funktion zur Aktualisierung des States.
							- State-Updates sind asynchron und führen zu einer neuen Render-Ausführung der Komponente.
					- 📬 Übergabe von Daten mit Props
						Props werden von einer Elternkomponente an eine Kindkomponente weitergereicht.
						Sie funktionieren ähnlich wie Funktionsargumente.
						Die Kindkomponente greift über das props-Objekt auf diese Daten zu.
						Innerhalb der Kindkomponente sind Props unveränderlich (read-only) – sie können dort nicht direkt verändert werden.
					- React Router ist eine Bibliothek für die Navigation in React-Anwendungen.
						Sie ermöglicht, dass verschiedene URLs unterschiedliche Komponenten anzeigen – ohne die Seite neu zu laden.
						Das Ergebnis ist eine Single-Page Application (SPA) mit dynamischer Navigation.
						🔧 Wichtige Komponenten
							BrowserRouter: Nutzt die History API des Browsers für sauberes Routing.
							Routes: Definiert alle verfügbaren Routen.
							Route: Verknüpft eine URL mit einer bestimmten Komponente.
							Link / NavLink: Erzeugt klickbare Links, um zwischen Seiten zu wechseln.

			- Einführung in Resful API's
				- REST (Representational State Transfer) ist ein Architekturstil für verteilte Systeme.
				- RESTful APIs sind Schnittstellen, die den Zugriff auf Ressourcen über das HTTP-Protokoll ermöglichen.
				- HTTP-Methoden (GET, POST, PUT, DELETE) werden verwendet, um Operationen auf Ressourcen durchzuführen (lesen, erstellen, aktualisieren, löschen).
				- Die Kommunikation erfolgt in der Regel über JSON (JavaScript Object Notation).
				- Restulf APIs in Spring Boot: ERSTELLUNG VON CONTROLLERN UND MAPPING VON ENDPUNKTEN 
					Controller: Eine Klasse in Spring Boot, die Anfragen entgegennimmt und verarbeitet.
					Endpunkte: URLs, die mit bestimmten HTTP-Methoden und Ressourcen verknüpft sind.
					Annotationen:
					@RestController: Markiert eine Klasse als Controller.
					@GetMapping, @PostMapping, @PutMapping, @DeleteMapping: Verknüpfen Methoden mit HTTP-Methoden und Endpunkten.
					@PathVariable: Extrahiert Werte aus der URL.
					@RequestBody: Extrahiert Daten aus dem Anfragekörper (meistens JSON).
